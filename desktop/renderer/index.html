    Network access

    Use the local address on this computer or a LAN address on the same network.

    1. Same network: share one of the LAN addresses above while the server is online.
    2. Internet access: configure router forwarding and the host firewall for this port. The manager cannot verify router rules or public reachability.
    3. Secure access: use a VPN or an HTTPS reverse proxy; do not expose the development server directly to the public internet.

    Settings

    Server binding, startup behaviour and secrets for this installation.

    Network

    Renaming applies when you press Save Server Config — the existing organization is updated in the database right away, with no server restart.

    Changing the port requires a server restart. Ports below 1024 are privileged on macOS and Linux. To serve the app over the internet, forward this port on your router and allow it through the firewall.

    Security

    The board token is added to the kiosk URL as ?token=....

    GitHub pull requests

    Optional. When a repository is listed and a token is saved, every open pull request becomes an unassigned task on the operations board, and the task closes when the pull request is merged or closed.

    Use a read-only token with access to the listed repositories. Clear the repository list to turn the sync off.
